# Little Ninja Safety Academy — Kids Shorts Engine

Production workspace for turning 3D episodes into YouTube Shorts (Made for Kids) and TikToks (parent-facing).
All rules live in [`CLAUDE.md`](CLAUDE.md). Run stages in Claude Code with `/pipeline <stage>`:

`voice` → `scout <topic>` → `study <url>` → `ideate` → `script <idea>` → `cut <id>` → `review <id>` · `status` anytime.

Video files in `episodes/raw/` and `shorts/` are git-ignored on purpose.
